# Google's "G" logo

`g-logo.svg` is Google's own standard-colour "G", from the official
Sign in with Google asset pack, used only inside the "Sign in with Google"
button as Google's branding guidelines require.

The guidelines forbid recolouring, redrawing, resizing or using it outside a
sign-in button, so do none of those. It is a Google trademark, not covered by
this project's licence. Rendered and checked in Chromium and WebKit on
02/10/2026.
